무료 진단

숏폼 제작 업체 비교, 견적서에서 꼭 볼 7가지 비용 기준

메가헤르츠 마케팅연구소 · 2026년 11월 08일

숏폼 제작 업체 비교는 월 금액보다 견적서에 무엇이 들어 있는지부터 봅니다. 편수, 수정 횟수, 업로드 범위 세 가지면 업체 간 차이가 드러납니다.

숏폼 제작 업체 비교는 월 금액보다 포함 범위부터

같은 월 금액이라도 업체마다 그 안에 담긴 일이 다릅니다. 편수와 포함 범위가 같아야 같은 선에서 견줄 수 있고, 그렇지 않으면 싸 보이던 곳이 실제로는 비싼 곳이 되기도 합니다.

예를 들어 월 100만 원(예시, 확인 필요)이라는 견적에 기획과 촬영이 빠져 있다면, 나중에 항목별 비용이 따로 붙어 최종 금액이 20%에서 40%까지 달라질 수 있습니다(예시, 확인 필요).

견적 항목표로 기획·촬영·편집 비용 나눠 보기

항목 없이 한 줄로 뭉친 견적은 어디에서 비용이 커지는지 확인할 수 없어 비교 자체가 어렵습니다.

아래 표처럼 기획, 촬영, 편집, 자막, 업로드를 나눠 받으면 업체별로 같은 항목끼리 맞춰 볼 수 있고, 어느 항목이 비싼지도 바로 보입니다.

| 항목 | 예시 금액(예시, 확인 필요) | 확인할 점 | |---|---|---| | 기획·대본 | 편당 5만 원에서 15만 원 | 대본 수정이 포함인지, 기획 회의 횟수가 정해져 있는지 | | 촬영 | 반일 30만 원에서 60만 원 | 장소 대관, 출연 인원, 촬영 시간 초과 시 추가 비용 | | 편집 | 편당 8만 원에서 20만 원 | 편집 길이 기준과 컷 수 제한이 있는지 | | 자막·썸네일 | 편당 2만 원에서 5만 원 | 별도 청구인지, 기본 포함인지 | | 업로드·관리 | 월 10만 원에서 30만 원 | 관리 채널 수, 게시 일정, 댓글 응대 범위 | | 월 4편 합계 | 100만 원에서 250만 원 | 편당 가격이 아닌 월 합계로 비교하는지 |

표의 금액은 모두 설명용 가정값(예시, 확인 필요)이며 실제 시장 가격이 아닙니다.

편수에 따라 편당 단가가 달라지는 이유

촬영을 하루에 몰아 찍는 구조에서는 편수가 늘수록 장소 섭외와 장비 세팅 비용을 나누는 폭이 커져 편당 단가가 내려가는 경우가 흔합니다.

예시로 월 12편은 월 4편보다 편당 단가가 10%에서 20% 낮게 책정될 수 있고, 편당 20만 원이던 구성이 16만 원에서 18만 원 선이 되는 식입니다(예시, 확인 필요).

다만 편수별 단가 차이는 업체마다 다르니 4편, 8편, 12편 기준 금액을 각각 적어 달라고 요청하고, 편수를 채우지 못한 달의 이월 조건도 함께 물어보세요.

수정 횟수 조건이 총비용을 바꿉니다

수정이 편당 2회까지 포함인지, 횟수 제한이 없는지에 따라 총비용이 크게 달라지므로 수정 횟수와 범위를 먼저 물어봐야 합니다.

조건이 적혀 있지 않으면 3회째 수정부터 편당 2만 원 추가(예시, 확인 필요) 같은 비용이 뒤늦게 나오고, 월 8편이면 수정 추가분만 16만 원이 됩니다(예시, 확인 필요).

자막 오타 수정과 컷 순서 변경, 촬영 분량을 다시 찍는 재촬영은 작업량이 전혀 다르니, 어디까지가 한 번의 수정인지도 문서에 적어 두는 편이 좋습니다.

| 수정 조건 유형 | 예시 총비용 영향(예시, 확인 필요) | 주의할 점 | |---|---|---| | 편당 2회 포함, 초과 시 유료 | 초과 1회당 2만 원 추가 | 초과 기준과 단가가 적혀 있는지 | | 횟수 제한 없음 | 월 금액에 이미 반영, 5%에서 15% 높게 책정되는 경우 | 무제한의 범위와 기한 제한 | | 횟수 미기재 | 분쟁 시 추가 청구 가능성 | 서면 확인 없이 진행하지 않기 |

계약서에 넣어 둘 문구 예시

아래는 예시 문구이며, 실제 계약 전에는 전문가 검토가 필요합니다.

① 편당 수정은 2회까지 포함하며 3회째부터 편당 2만 원을 별도 청구한다. ② 수정 요청은 접수 후 영업일 기준 3일 이내에 반영한다. ③ 원본 영상과 자막 파일은 계약 종료 후 7일 이내에 전달한다.

④ 중도 해지 시 제작이 끝난 편수의 비용을 뺀 나머지 금액을 14일 이내에 환불한다.

수정 횟수, 반영 기한, 원본 전달 같은 조건은 말이 아니라 문서로 남겨야 나중에 책임 범위를 두고 다투는 일을 줄일 수 있습니다.

제작 기간은 이런 순서로 흘러갑니다

일반적인 순서는 상담, 기획안 확인, 촬영, 1차 편집본, 수정, 업로드이며 첫 편은 단계마다 확인이 들어가 시간이 더 걸립니다.

예시로 첫 편 기준 기획 3일, 촬영 1일, 편집 5일, 수정 2일, 업로드 준비 1일이면 약 12일이고, 둘째 편부터는 촬영을 묶으면 7일에서 10일로 줄어드는 구성도 있습니다(예시, 확인 필요).

각 단계 기한을 날짜로 받아 두고, 비용 구성은 [쇼츠 제작 비용 구성](/blog/shorts-production-cost.html), 기획 순서는 [숏폼 기획안 작성 순서](/blog/shortform-planning-order.html) 글을 함께 보세요.

좋은 견적서 다시 확인할 점검표

견적서를 받았다면 아래 표의 일곱 항목을 하나씩 대조해, 말로만 들은 조건이 문서에도 그대로 적혀 있는지 한 번 더 확인하세요.

| 점검 항목 | 확인 기준 | 체크 | |---|---|---| | 편수 | 월 몇 편인지 숫자로 적혀 있고, 미달 시 처리 방식이 있는지 | □ | | 수정 | 편당 수정 횟수, 초과 시 추가 비용, 수정 범위가 적혀 있는지 | □ | | 길이 | 편당 15초에서 60초 등 영상 길이 기준이 명시되어 있는지 | □ | | 원본 | 원본 영상과 자막 파일 전달 시점, 파일 형식이 있는지 | □ | | 업로드 | 게시 채널 수, 게시 일정, 계정 권한 소유자가 적혀 있는지 | □ | | 일정 | 첫 편 납기와 단계별 기한이 날짜로 적혀 있는지 | □ | | 해지 | 중도 해지 시 환불 기준과 제작 완료분 정산 방식이 있는지 | □ |

빈칸이 없는 견적서인지 보고, 한 칸이라도 비어 있으면 서면 답변을 요청하는 편이 안전합니다.

숏폼 제작 업체 비교에서 걸러야 할 신호

성과를 약속하는 문구는 업체가 정할 수 없는 조회수와 문의 수를 말하는 것이므로, 근거와 조건 없이 숫자만 내세우는 제안은 조심해야 합니다.

포트폴리오는 어떤 업종 영상을 직접 만들었는지, 누구의 계정에 올렸던 영상인지 확인하고, 원본 파일과 계정 권한을 계약 종료 후에도 넘겨주는 곳인지 물어보세요.

의료 분야는 의료법 제56조, 후기·협찬 영상은 공정위 추천·보증 심사지침을 지키는 업체인지 사전 검수 절차까지 확인합니다.

상담 전에 스스로 답해 볼 질문 2개

첫째, 한 달에 몇 편을 올릴 시간과 촬영 협조 여건이 우리 매장에 실제로 있는가. 둘째, 영상으로 얻고 싶은 것이 조회수인지, 문의인지, 방문 예약인지 한 가지로 정했는가. 이 두 답이 정해지면 견적서의 편수와 수정 조건을 훨씬 쉽게 가를 수 있습니다.

자주 묻는 질문

Q. 숏폼 제작 비용은 보통 얼마인가요?
편수, 촬영 방식, 수정 조건에 따라 달라 하나의 금액으로 말하기 어렵습니다. 이 글의 금액은 월 4편 기준 100만 원에서 250만 원처럼 설명용 예시(확인 필요)일 뿐 시장 가격이 아닙니다. 같은 조건으로 2곳에서 3곳의 견적을 항목별로 받아 비교하세요.
Q. 제작 기간은 얼마나 걸리나요?
첫 편은 기획부터 업로드까지 예시로 2주 안팎이 걸릴 수 있습니다(예시, 확인 필요). 이후에는 촬영 일정을 묶으면 짧아질 수 있으니 단계별 기한을 문서로 받아 두세요.
Q. 견적서에서 가장 먼저 볼 항목은 무엇인가요?
편수와 수정 횟수입니다. 두 조건이 같아야 월 금액을 비교할 수 있고, 추가 비용이 생기는 기준도 이 두 항목에서 정해지는 경우가 많습니다.
Q. 조회수나 순위를 약속하는 업체를 맡겨도 되나요?
조회수와 노출 순위는 플랫폼 상황에 따라 달라 업체가 단정할 수 없습니다. 약속 문구가 있다면 근거와 조건을 서면으로 요청하고, 없다면 신중하게 판단하세요.
