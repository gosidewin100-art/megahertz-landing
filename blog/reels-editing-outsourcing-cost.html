무료 진단

릴스 편집 외주 비용, 견적 항목과 수정 횟수 확인 기준

메가헤르츠 마케팅연구소 · 2026년 11월 07일

릴스 편집 외주 비용은 편수, 영상 길이, 수정 횟수로 정해집니다. 건당 단가만 비교하면 자막과 수정 비용이 빠져 최종 금액이 달라질 수 있습니다. 견적서에 항목별 금액과 수정 횟수가 적혀 있는지부터 확인하세요. 아래 금액은 설명용 예시 가정값입니다.

릴스 편집 외주 비용을 정하는 세 가지 변수

편집 시간을 좌우하는 것은 영상 길이, 컷 수, 자막 양입니다. 촬영본이 길고 컷이 잦고 자막이 많을수록 작업 시간이 늘어나고, 그만큼 건당 단가가 올라갑니다. 업체는 이 시간을 건당 금액으로 환산해 제시하므로 편수와 난이도가 견적의 뼈대가 되고, 같은 30초 영상이라도 구성에 따라 금액이 갈립니다.

릴스 편집 외주 비용 견적 항목별 예시 금액

견적서는 한 줄 총액이 아니라 항목별로 받아야 업체끼리 비교가 됩니다. 아래 금액은 시장에서 확인한 값이 아니라 설명용으로 둔 가정값이며, 실제 단가는 업체별 견적으로 반드시 확인해야 합니다.

| 견적 항목 | 예시 가정값, 확인 필요 | 포함 내용 | |---|---|---| | 기본 편집 (30초 내외) | 건당 30,000원 | 컷 편집, 음악 삽입, 기본 자막 | | 기본 편집 (60초 내외) | 건당 50,000원 | 컷 편집, 음악 삽입, 기본 자막 | | 모션 자막 추가 | 건당 10,000원 | 강조 자막, 효과 자막, 단어별 움직임 | | 커버 이미지 | 건당 5,000원 | 첫 화면 문구 디자인 | | 추가 수정 1회 | 회당 10,000원 | 기본 수정 횟수를 넘긴 분량 | | 촬영 기획 포함 | 월 300,000원 | 소재 정리, 대본 구성, 촬영 가이드 | | 급행 납품 | 기본 단가의 20% 가산 | 납품 일정을 당길 때 적용 | | 원본 파일 제공 | 별도 협의 | 프로젝트 파일 포함 여부 확인 | | 숏폼 3종 묶음 편집 | 월 4편 기준 협의 | 편수가 늘 때 단가 조정 가능 여부 | | 자막 번역본 추가 | 건당 15,000원 | 외국어 자막 버전 제작 |

월 게시물 수 × 단가 × 개월로 총액 계산

총액은 월 게시물 수 × 단가 × 개월로 계산하며, 아래 숫자는 모두 예시 가정값입니다(확인 필요). 월 8편 × 건당 40,000원 × 3개월은 960,000원이고, 월 12편 × 건당 35,000원 × 6개월은 2,520,000원입니다. 편수가 늘면 건당 단가가 낮아지는 조건이 있는지, 자막과 수정 비용이 총액에 들어 있는지 함께 물어야 합니다.

| 시나리오 | 계산식 | 총액 (예시 가정값, 확인 필요) | |---|---|---| | 가볍게 시작 | 월 4편 × 건당 45,000원 × 3개월 | 540,000원 | | 꾸준히 운영 | 월 8편 × 건당 40,000원 × 3개월 | 960,000원 | | 집중 운영 | 월 12편 × 건당 35,000원 × 6개월 | 2,520,000원 | | 모션 자막 포함 | 월 8편 × (건당 40,000원 + 자막 10,000원) × 3개월 | 1,200,000원 |

릴스 편집 외주 비용이 달라지는 조건

촬영본 정리 상태, 자막 양, 효과 수준, 납품 속도가 같은 영상의 가격을 바꿉니다. 특히 급행 가산은 견적서에 비율로 적혀 있는지 확인해야 하고, 효과가 많은 영상은 기본 단가가 아니라 별도 항목으로 잡히는지도 봐야 합니다. 급행 가산을 20%로 가정하면 건당 30,000원 영상은 36,000원이 됩니다.

| 달라지는 조건 | 견적에 미치는 영향 | |---|---| | 촬영본이 흩어져 있고 컷 선별이 필요하다 | 선별 시간이 더해져 단가가 올라갈 수 있다 | | 대사 전체에 자막을 넣고 단어별 효과를 준다 | 모션 자막 항목이 별도로 붙는다 | | 로고, 가격표, 지도 같은 그래픽을 넣는다 | 그래픽 작업 항목이 추가될 수 있다 | | 같은 소스를 세로와 가로로 각각 납품한다 | 규격별로 편수가 계산될 수 있다 | | 납품 일정을 평소보다 크게 당긴다 | 급행 가산 비율이 적용될 수 있다 |

수정 횟수와 계약서 문구 예시

수정 횟수는 견적서에 숫자로 적어야 분쟁이 줄어듭니다. 문구 예시는 '기본 수정 2회 포함, 3회부터 회당 10,000원 추가'입니다. '수정 무제한'처럼 범위 없는 표기는 나중에 해석이 달라질 수 있으니, 아래 표처럼 범위와 기한을 함께 적어 두세요.

| 계약 항목 | 문구 예시 (업체와 협의해 조정) | |---|---| | 수정 횟수 | 기본 수정 2회 포함, 3회부터 회당 10,000원 추가 | | 수정 범위 | 자막 오탈자, 컷 순서, 음악 교체로 한정 | | 수정 요청 기한 | 시안 전달 후 3일 이내 요청분만 기본 횟수에 포함 | | 납품 일정 | 촬영본과 자막 문구 수령 후 영업일 기준 5일 이내 1차 시안 전달 | | 음원과 폰트 | 상업 이용이 가능한 출처의 소스만 사용 | | 파일 제공 | 최종 납품 후 프로젝트 파일 제공 여부를 별도로 명시 | | 계약 해지 | 제작 착수 후 해지 시 진행분 기준으로 정산 |

좋은 답과 다시 확인할 답 점검표

상담 때 같은 질문을 여러 업체에 하고 답을 표로 비교하세요. 답이 구체적일수록 계약 후 금액이 달라질 여지가 줄어듭니다.

| 좋은 답 | 다시 확인할 답 | |---|---| | 건당 단가와 포함 범위를 항목별로 안내한다 | 패키지 가격만 말하고 내역은 계약 후 알려 준다 | | 기본 수정 횟수와 추가 비용을 숫자로 안내한다 | 수정은 알아서 해 드린다고만 답한다 | | 원본 파일과 프로젝트 파일 제공 여부를 적어 준다 | 납품 후 원본 제공 여부에 답을 피한다 | | 1차 시안과 최종 납품 일정을 일 단위로 안내한다 | 빠르게 해 드린다고만 답한다 | | 음원과 폰트의 사용 범위와 출처를 설명한다 | 출처를 물으면 구체적인 답이 없다 | | 업종과 채널에 맞춘 구성안을 먼저 제시한다 | 어떤 업종이든 같은 템플릿을 쓴다고 답한다 | | 급행 가산과 추가 항목을 비율과 금액으로 안내한다 | 필요하면 그때 말씀드린다고 답한다 | | 계약 해지 조건과 환불 기준을 문서로 보여 준다 | 구두로만 설명하고 문서는 나중에 준다고 한다 | | 시안 전달 방식과 수정 요청 창구를 정해 둔다 | 연락이 닿는 시간과 방식이 정해져 있지 않다 |

릴스 편집 외주 비용 계약 후 진행 순서와 기간

순서는 요청서 전달, 견적 확인, 계약, 1차 시안, 수정, 최종 납품입니다. 1차 시안 일정은 편수와 수정 횟수에 따라 달라지므로 계약 전에 일 단위로 받아 두세요. 월 8편이라면 주 2편 × 4주로 나눠 주 단위 납품 일정을 정해 두면 촬영과 업로드 관리가 쉬워집니다.

| 진행 단계 | 이 단계에서 확인할 것 | |---|---| | 요청서 전달 | 업종, 편수, 참고 릴스, 촬영본 양 | | 견적 확인 | 항목별 금액, 포함 범위, 수정 횟수 | | 계약 | 납품 일정, 수정 범위, 음원 출처 | | 1차 시안 | 자막 오탈자, 컷 순서, 첫 3초 구성 | | 수정 | 남은 수정 횟수와 반영 기한 | | 최종 납품 | 파일 형식, 커버 이미지, 원본 제공 여부 |

촬영본 준비로 비용 줄이는 방법

원본을 폴더별로 정리하고 쓸 컷에 표시해서 넘기면 업체가 컷을 고르는 시간이 줄어 견적 조정 여지가 생깁니다. 자막 문구와 로고 파일을 미리 확정해 주면 수정 횟수도 아낄 수 있습니다. 다만 수정 횟수를 0으로 깎는 조건은 품질 문제로 이어질 수 있어 권하지 않습니다.

| 준비물 | 미리 정해 두면 줄어드는 것 | |---|---| | 컷 선별 표시가 된 촬영본 | 컷 고르는 시간 | | 확정된 자막 문구 | 자막 수정 횟수 | | 로고와 브랜드 색상 파일 | 그래픽 재작업 | | 참고 릴스 링크 3개 | 분위기와 속도에 대한 해석 차이 |

상담 전에 준비할 것과 문의 방법

촬영 전 준비는 [숏폼 제작 진행 순서](/blog/shortform-production-process.html)를 함께 보시고, 업종, 월 목표 편수, 참고하고 싶은 릴스 3개, 보유한 촬영본 양을 정리해 두세요.

메가헤르츠는 현재 릴스 운영 상태를 보고 필요한 편수와 수정 범위를 정리해 드리는 무료 진단과 상담을 받고 있습니다. 다른 곳에서 받은 견적서를 비교해 보고 싶은 분도 부담 없이 신청해 주세요. 신청하시면 업종과 목표에 맞춰 항목별 견적 구성을 안내해 드립니다.

자주 묻는 질문

Q. 릴스 편집 외주 비용은 한 편에 얼마인가요?
영상 길이, 자막 양, 수정 횟수에 따라 업체마다 달라서 한 가지 금액을 말하기 어렵습니다. 이 글의 건당 30,000원은 설명용 예시 가정값이므로 실제 견적서로 확인하세요. 항목별 내역과 포함 범위를 받으면 업체 간 비교가 쉬워집니다.
Q. 릴스 편집 기간은 보통 얼마나 걸리나요?
편수, 영상 길이, 업체 작업 일정에 따라 다릅니다. 계약 전에 1차 시안과 최종 납품 일정을 일 단위로 받아 두는 것이 좋습니다.
Q. 수정 횟수를 넘기면 추가 비용이 드나요?
기본 수정 횟수를 넘기면 회당 추가 비용을 받는 업체가 많습니다. 기본 수정 횟수와 초과 단가, 수정 범위를 견적서나 계약서에 적어 두면 분쟁을 줄일 수 있습니다.
Q. 건별 계약과 월 단위 계약 중 무엇이 나은가요?
편수가 적고 시험 삼아 맡긴다면 건별 계약이, 매달 꾸준히 올린다면 월 단위 계약이 단가 협의에 유리할 수 있습니다. 월 단위는 총 편수와 개월 수를 곱해 총액을 먼저 확인하세요.
