# 썸네일 v2 — 모델 사진 + 후킹 문구 (2026-09-22, 대표 지시)

기존 텍스트 카드 대신 **실사 모델 사진 배경 + 왼쪽 그라데이션 + 큰 후킹 문구** 스타일.
클릭률 개선 목적. 적용 예: blog/img/reels-algorithm-reset/thumb.png

사용 (Pillow 필요, Windows Malgun Gothic 폰트 경로 하드코딩):
    python megahertz_thumb.py <사진> <출력> "제목줄1|제목줄2" "노랑강조줄" ["하단소제목"]

models/ 에 재사용 가능한 모델 사진 4장 (제미나이 생성, 상업이용 시 주의사항 없음 확인).
새 모델 사진이 필요하면 제미나이에 "사진처럼 사실적인 20대 한국인 여성 ... 인물 오른쪽 배치,
왼쪽 텍스트 여백, 1:1 정사각형" 프롬프트로 생성.

**일일 생성기에 적용 권장**: 새 글 발행 시 이 스타일로 thumb.png 생성 (인스타·릴스·뷰티·체험단
등 소비자성 주제 우선, 지역 견적성 글은 기존 스타일 유지해도 무방).
